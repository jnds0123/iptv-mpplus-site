Orpheus Property Console

Working prototype. The guest television and the operations console run off one shared guest record — act on one, watch the other change.

Try this: on the television, open Order and send something to Room 812. Then switch to the Hotel console — the kitchen order, the service ticket and the folio line are already there, because there is only one record behind both screens.

Remote

Your keyboard arrows, Enter and Backspace drive the screen too — the same four inputs a hotel remote has.
