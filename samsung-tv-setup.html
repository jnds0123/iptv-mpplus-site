Samsung TV Setup — IPTV Multimedia Player Plus

This guide walks through installing IPTV MP+ on a Samsung Smart TV (Tizen, 2016 or newer) and adding your provider. The examples below use the TV IP address 10.0.4.209 — replace it with your own TV's IP if it differs.

1. Give the TV a fixed IP address

  1. On the TV, open Settings → General → Network → Network Status → IP Settings.
  2. Set IP Setting to Enter manually and enter the address (e.g. 10.0.4.209), subnet mask 255.255.255.0, and your router's gateway and DNS.
  3. Confirm the TV shows "Connected to the Internet".

2. Enable Developer Mode on the TV

  1. Open the Apps panel on the TV.
  2. On the remote, press 1 2 3 4 5 (on older models: enter 12345 in the search box). The Developer Mode dialog appears.
  3. Switch Developer Mode to On.
  4. In Host PC IP, enter the IP address of the computer you will install from (not the TV's own IP).
  5. Restart the TV (hold the power button until it reboots).

3. Install IPTV MP+ from your computer

You need Tizen Studio (with the TV extension) and a Samsung certificate profile.

  1. Open Device Manager in Tizen Studio and connect to the TV: 10.0.4.209, port 26101 — or from a terminal: sdb connect 10.0.4.209.
  2. In the Certificate Manager, create a Samsung certificate and add your TV's DUID (Device Manager shows it once connected).
  3. Install the signed package: tizen install -n IPTVMPPlus.wgt -t <device> (or right-click the project → Run As → Tizen Web Application).
  4. IPTV MP+ now appears in the TV's Apps panel.

4. Add your provider in the app

  1. Open IPTV MP+ on the TV.
  2. Choose Add Playlist and pick the type your provider gave you:
    • Xtream Codes login — server address (e.g. your provider's portal such as orpheusnations.com with the port they specify), plus your username and password.
    • M3U / M3U8 URL — paste the full playlist link.
  3. Optionally add the XMLTV EPG URL from your provider for the program guide.
  4. Save — channels, movies, and series load and are cached on the TV.

Note: IPTV MP+ ships with no content or providers. Add only playlists and subscriptions you are legally entitled to access — see our privacy policy.

Troubleshooting

  • Device Manager can't connect: the TV and computer must be on the same network; re-check that Developer Mode shows On and the Host PC IP matches your computer, then restart the TV.
  • "Non trusted certificate" on install: the certificate profile is missing the TV's DUID — regenerate it with the DUID included.
  • Developer Mode apps disappear: sideloaded apps are removed if the TV leaves Developer Mode or after some firmware updates; reinstall from step 3.
  • Channels won't load: verify the portal address, port, and credentials with your provider, and test the same login in the app on another device.
