Samsung Smart TV Setup Guide

Developer-mode host IP for this setup: 10.0.4.209

Important: Samsung Smart TVs run Tizen OS, not Android. IPTV Multimedia Player Plus (IPTV MP+) is an Android app, so it cannot be installed directly on a Samsung TV. See the options below for using IPTV MP+ with a Samsung TV, and for loading provider apps (such as one from your IPTV provider) onto the TV itself.

Step 1 — Enable Developer Mode and set the host IP

This unlocks the TV so apps can be pushed to it from a computer on your network (the machine at 10.0.4.209).

  1. Press Home on the remote and open the Apps panel.
  2. With the Apps panel open, press 1 2 3 4 5 on the remote's number pad. A Developer mode dialog appears. (On some models it's under Apps → Settings gear → typing 12345.)
  3. Switch Developer mode On.
  4. When asked for the Host PC IP, enter 10.0.4.209 and confirm.
  5. Turn the TV fully off and back on (unplug for ~30 seconds if needed). "Developer mode" should now show at the top of the Apps panel.

Step 2 — Find your TV's IP address

You'll need it to connect from the computer:

Settings → General → Network → Network Status → IP Settings — note the TV's IP (it will be another 10.0.4.x address on your network).

Step 3 — Install a provider app on the TV

If your IPTV provider (for example, orpheusnations.com) supplies a Samsung/Tizen app:

  • If it's in the Samsung App Store: Home → Apps → Search, type the app name, and install it — no developer mode needed. Ask the provider for the exact app name.
  • If it's a .wgt file (Tizen widget): on the computer at 10.0.4.209, install Tizen Studio (or just its CLI tools), then run:
    1. sdb connect <TV-IP-from-Step-2> — accept the permission prompt on the TV.
    2. tizen install -n YourProviderApp.wgt -t <device-name>
    The app then appears in the TV's Apps panel.
  • If the provider gives you a "server IP" or portal URL instead: that goes inside an IPTV player app (as an Xtream Codes login or M3U playlist URL) — you don't need developer mode for that, just a player app from the Samsung App Store.

Step 4 — Using IPTV MP+ with a Samsung TV

Since IPTV MP+ is Android-only, pick one of these:

  • Android TV / Google TV device: plug a Chromecast with Google TV, onn. box, NVIDIA Shield, or similar into the Samsung TV's HDMI port and install IPTV MP+ on it from the Play Store. This gives you the full IPTV MP+ experience on the big screen.
  • Cast from your phone/tablet: run IPTV MP+ on Android and cast to a Chromecast device connected to the TV.
  • Native Samsung player: install an IPTV player from the Samsung App Store and enter the same playlist or Xtream Codes credentials you use in IPTV MP+ — your provider subscription works in either app.

Troubleshooting

  • 12345 does nothing: make sure the Apps panel itself is focused (not a search box), and try the on-screen number pad on remotes without number keys.
  • TV not found by sdb connect: confirm the TV and the computer at 10.0.4.209 are on the same network/VLAN, and that the host IP entered in Developer mode exactly matches the computer's current IP.
  • Sideloaded app disappears: developer-mode installs can be removed by TV firmware updates; reinstall with the same steps.
